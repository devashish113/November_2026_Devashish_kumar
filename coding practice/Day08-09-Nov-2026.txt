## 🔹 Task 1 — Ansible: Install Docker Compose
Playbook to install python3-pip and Docker Compose using the pip module:
```yaml
---
- name: Install Docker Compose
  hosts: all
  become: yes
  tasks:
    - name: Install dependencies
      yum:
        name: python3-pip
        state: present

    - name: Install docker-compose
      pip:
        name: docker-compose
```

## 🔹 Task 2 — Terraform: EC2 with Security Group & 30GB EBS Storage
Provisions an AWS EC2 instance (`t3.medium`) with ingress rules for SSH and HTTP, attached with a 30GB EBS block device:
```hcl
resource "aws_security_group" "allow_ssh_http" {
  name        = "allow_ssh_http"
  description = "Allow SSH and HTTP access"

  ingress {
    from_port   = 22
    to_port     = 22
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  ingress {
    from_port   = 80
    to_port     = 80
    protocol    = "tcp"
    cidr_blocks = ["0.0.0.0/0"]
  }

  egress {
    from_port   = 0
    to_port     = 0
    protocol    = "-1"
    cidr_blocks = ["0.0.0.0/0"]
  }
}

resource "aws_instance" "pathnex_ec2" {
  ami             = "ami-0abcd1234abcd1234"
  instance_type   = "t3.medium"
  security_groups = [aws_security_group.allow_ssh_http.name]

  ebs_block_device {
    device_name = "/dev/sdh"
    volume_size = 30
  }

  tags = {
    Name = "Pathnex-EC2-Storage"
  }
}
```

## 🔹 Task 3 — Kubernetes: Service with NodePort
Exposes application deployment outside the cluster on a static port (30007):
```yaml
apiVersion: v1
kind: Service
metadata:
  name: pathnex-service
spec:
  type: NodePort
  selector:
    app: pathnex-app
  ports:
    - protocol: TCP
      port: 80
      targetPort: 80
      nodePort: 30007
```

## 🔹 Task 4 — Jenkinsfile: Docker Build and Push
Pipeline using Jenkins Docker plugin to build and push container images to Docker Hub:
```groovy
pipeline {
    agent any
    stages {
        stage('Build Docker Image') {
            steps {
                script {
                    docker.build('pathnex-app')
                }
            }
        }
        stage('Push Docker Image') {
            steps {
                script {
                    docker.withRegistry('https://docker.io', 'docker-credentials') {
                        docker.image('pathnex-app').push('latest')
                    }
                }
            }
        }
    }
}
```

## 🔹 Task 5 — GitLab CI/CD: Automated Container Delivery
Builds and authenticates against GitLab Container Registry before pushing:
```yaml
stages:
  - build
  - push

build:
  stage: build
  script:
    - docker build -t pathnex-app .

push:
  stage: push
  script:
    - docker login -u "$CI_REGISTRY_USER" -p "$CI_REGISTRY_PASSWORD"
    - docker push pathnex-app
```
