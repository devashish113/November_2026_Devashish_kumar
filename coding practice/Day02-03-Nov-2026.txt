## 🔹 Task 1 — Ansible: Install and Enable Nginx
Playbook for installing and starting the Nginx service on Pathnex hosts:
```yaml
---
- name: Install and start Nginx on Pathnex
  hosts: all
  become: yes

  tasks:
    - name: Install nginx
      yum:
        name: nginx
        state: present

    - name: Enable nginx
      service:
        name: nginx
        state: started
        enabled: yes
```

## 🔹 Task 2 — Terraform: EC2 with Custom Tags (r5.2xlarge)
Provisioning an AWS EC2 instance with specific training tags:
```hcl
provider "aws" {
  region = "us-east-1"
}

resource "aws_instance" "PathnexEC2" {
  ami           = "ami-0abcd1234abcd1234"
  instance_type = "r5.2xlarge"

  tags = {
    Name        = "Pathnex-Server"
    Environment = "Training"
    Owner       = "PathnexStudent"
  }
}
```

## 🔹 Task 3 — Kubernetes: Deployment with 2 Replicas
Deploying a 2-replica Nginx application:
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: pathnex-deployment
spec:
  replicas: 2
  selector:
    matchLabels:
      app: pathnex-app
  template:
    metadata:
      labels:
        app: pathnex-app
    spec:
      containers:
        - name: app
          image: nginx
          ports:
            - containerPort: 80
```
