## 🔹 Task 1 — Ansible: Install Docker Engine
Automated installation and service startup for Docker:
```yaml
---
- name: Install Docker
  hosts: all
  become: yes
  tasks:
    - name: Install Docker
      yum:
        name: docker
        state: present
    - name: Start Docker
      service:
        name: docker
        state: started
        enabled: yes
```

## 🔹 Task 2 — Terraform: Provisioning EC2 within a Custom VPC
Configuring a custom VPC (`10.0.0.0/16`), subnet, and deploying an EC2 instance into it:
```hcl
resource "aws_vpc" "main" {
  cidr_block = "10.0.0.0/16"

  tags = {
    Name = "Pathnex-VPC"
  }
}

resource "aws_subnet" "main" {
  vpc_id            = aws_vpc.main.id
  cidr_block        = "10.0.1.0/24"
  availability_zone = "us-east-1a"

  tags = {
    Name = "Pathnex-Subnet"
  }
}

resource "aws_instance" "pathnex_ec2" {
  ami           = "ami-0abcd1234abcd1234"
  instance_type = "t3.medium"
  subnet_id     = aws_subnet.main.id

  tags = {
    Name = "Pathnex-EC2"
  }
}
```

## 🔹 Task 3 — Kubernetes: Pod with hostPath Volume Mount
Configuring persistent host volume sharing inside a pod container:
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: pathnex-pod
spec:
  containers:
    - name: web
      image: nginx
      volumeMounts:
        - mountPath: /usr/share/nginx/html
          name: html-volume
  volumes:
    - name: html-volume
      hostPath:
        path: /data
        type: Directory
```

## 🔹 Task 4 — Shell Script: Checking Active System Services
Bash script to verify status of essential DevOps services (`nginx`, `docker`, `httpd`):
```bash
#!/bin/bash
services=("nginx" "docker" "httpd")
for service in "${services[@]}"
do
  if systemctl is-active --quiet $service; then
    echo "$service is running"
  else
    echo "$service is not running"
  fi
done
```
