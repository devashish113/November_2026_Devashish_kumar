## 🔹 Task 1 — Ansible: Setup Docker Container for Nginx
Automates image pulling and running an Nginx container with port forwarding (8080:80):
```yaml
---
- name: Setup Docker Container for Nginx
  hosts: all
  become: yes
  tasks:
    - name: Pull Nginx image
      docker_image:
        name: nginx
        source: pull

    - name: Run Nginx container
      docker_container:
        name: nginx-container
        image: nginx
        state: started
        published_ports:
          - "8080:80"
```

## 🔹 Task 2 — Terraform: EC2 with Auto Scaling Group (ASG)
Configures Launch Configuration and Auto Scaling Group across availability subnets:
```hcl
resource "aws_launch_configuration" "example" {
  name          = "pathnex-launch-config"
  image_id      = "ami-0abcd1234abcd1234"
  instance_type = "t3.medium"
}

resource "aws_autoscaling_group" "example" {
  name                 = "pathnex-asg"
  desired_capacity     = 2
  max_size             = 3
  min_size             = 1
  vpc_zone_identifier  = ["subnet-12345678"]
  launch_configuration = aws_launch_configuration.example.id
}
```

## 🔹 Task 3 — Kubernetes: Horizontal Pod Autoscaler (HPA)
Deployment paired with an HPA resource to dynamically scale between 1 and 10 pods based on 50% target CPU utilization:
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: pathnex-deployment
spec:
  replicas: 1
  selector:
    matchLabels:
      app: pathnex-app
  template:
    metadata:
      labels:
        app: pathnex-app
    spec:
      containers:
        - name: nginx
          image: nginx
          ports:
            - containerPort: 80
---
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: pathnex-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: pathnex-deployment
  minReplicas: 1
  maxReplicas: 10
  targetCPUUtilizationPercentage: 50
```

## 🔹 Task 4 — Jenkinsfile: Deploy to Kubernetes
Scripted stage executing cluster manifests using kubectl:
```groovy
pipeline {
    agent any
    stages {
        stage('Deploy to Kubernetes') {
            steps {
                script {
                    sh 'kubectl apply -f deployment.yaml'
                }
            }
        }
    }
}
```
