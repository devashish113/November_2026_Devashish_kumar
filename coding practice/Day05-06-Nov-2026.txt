## 🔹 Task 1 — Jenkinsfile: Git Integration and Testing
Declarative pipeline that pulls code from a remote Git repository, executes builds, unit tests, and triggers deployment:
```groovy
pipeline {
    agent any
    stages {
        stage('Clone Repository') {
            steps {
                git 'https://github.com/pathnex/sample-repo.git'
            }
        }
        stage('Build') {
            steps {
                echo 'Building project from Git repository'
            }
        }
        stage('Test') {
            steps {
                echo 'Running unit tests'
            }
        }
        stage('Deploy') {
            steps {
                echo 'Deploying application'
            }
        }
    }
}
```

## 🔹 Task 2 — GitLab CI/CD: Docker Build, Push and Kubernetes Deploy
Complete automated container delivery pipeline in `.gitlab-ci.yml`:
```yaml
stages:
  - build
  - push
  - deploy

build:
  stage: build
  script:
    - docker build -t pathnex-app .

push:
  stage: push
  script:
    - docker push pathnex-app

deploy:
  stage: deploy
  script:
    - kubectl apply -f kubernetes/deployment.yaml
```

## 🔹 Task 3 — Ansible: User Creation and Permissions
Ansible playbook to manage system users and directory permission modes:
```yaml
---
- name: Create a new user
  hosts: all
  become: yes
  tasks:
    - name: Create user
      user:
        name: pathnex
        state: present
        shell: /bin/bash

    - name: Set permissions for the user
      file:
        path: /home/pathnex
        owner: pathnex
        group: pathnex
        mode: '0755'
```

## 🔹 Task 4 — Terraform: EC2 with Attached EBS Storage
Provisions an AWS EC2 instance (`t2.medium`) with an additional 50GB EBS block storage device:
```hcl
resource "aws_instance" "PathnexEC2" {
  ami           = "ami-0abcd1234abcd1234"
  instance_type = "t2.medium"

  tags = {
    Name = "Pathnex-Server"
  }

  ebs_block_device {
    device_name = "/dev/sdh"
    volume_size = 50
  }
}
```
