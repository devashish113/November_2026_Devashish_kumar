## 🔹 Task 1 — Ansible: Install Nginx on Pathnex Server
Playbook:
```yaml
---
- name: Install Nginx on Pathnex server
  hosts: all
  become: yes

  tasks:
    - name: Install nginx package
      apt:
        name: nginx
        state: present
        update_cache: yes

    - name: Ensure nginx service is running and enabled
      service:
        name: nginx
        state: started
        enabled: yes
```
