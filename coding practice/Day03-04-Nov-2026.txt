## 🔹 Task 1 — Ansible: Install and Start Apache
Playbook to install httpd and enable service startup on boot:
```yaml
---
- name: Install and Start Apache
  hosts: all
  become: yes

  tasks:
    - name: Install apache
      yum:
        name: httpd
        state: present

    - name: Start apache
      service:
        name: httpd
        state: started
        enabled: yes
```

## 🔹 Task 3 — Kubernetes: ReplicaSet with 3 Replicas
Configured a ReplicaSet to maintain 3 healthy Nginx pods:
```yaml
apiVersion: apps/v1
kind: ReplicaSet
metadata:
  name: pathnex-replicaset
spec:
  replicas: 3
  selector:
    matchLabels:
      app: pathnex-app
  template:
    metadata:
      labels:
        app: pathnex-app
    spec:
      containers:
        - name: app
          image: nginx
          ports:
            - containerPort: 80
```

## 🔹 Task 4 — Shell Script: User Information
Bash script displaying current user name and group affiliations:
```bash
#!/bin/bash
echo "Current user: $(whoami)"
echo "Current user groups: $(groups)"
```


```dockerfile

COPY index.html /usr/share/nginx/html/index.html
```

Build and run commands:
